Привет! Прикладываю TZ_tender_bot.md — ТЗ на тендер-бот «Союз ивент тендеры» и «Завод тендеров» (v1.15).

ГЛАВНОЕ
Файл — единственный источник правды. Если он расходится с прежними инструкциями или с текущим ботом — прав файл.

КАК РАБОТАЕМ
1. Прочитай ТЗ целиком, включая Приложение А в конце.
2. Сначала без кода: сравни текущего бота с ТЗ и пришли список — что работает как в ТЗ, что иначе, чего нет.
3. Потом исправляй по шагам, в таком порядке:
   1) Ошибки из Приложения А (разбор прогона тендера Sunlight с Bidzaar).
   2) Сообщения в Telegram (9.2): HTML вместо ** и ##, без таблиц в чате, один блок — одно сообщение.
   3) Порядок этапов Ивента (6.1); каждый агент получает результаты всех предыдущих этапов.
   4) Распаковка: оценка + «Уточнить» / «Продолжить без уточнения» (6.0.4), ключевой показатель (6.0.2).
   5) 3 концепции, 3 площадки, 3 сметы без выбора внутри завода (6.0.6); при нескольких лотах — на каждый лот (6.0.5).
   6) Смета строго по 6.1.4.
   7) Оформление (7.0) и мерч (7.1, только если есть в ТЗ) — до сметы.
   8) Презентация по требованиям 7.3.1.
   9) Дальше по разделу 13: классификатор направлений, Продакшн, Креатив, Онлайн, КП.
4. После каждого шага — коротко что сделано + результат на тендере Sunlight. Дальше — только после моего «ок».

ПРАВИЛА
- Ничего не придумывай: только текст ТЗ тендера или источник из интернета. Допущения помечай «⚠️ допущение».
- Не меняй без моего согласия:
  • организация мероприятия — 150 000 ₽;
  • налог УСН 15%: ИТОГО ПО ПРОЕКТУ = ИТОГО ÷ 0,85;
  • тимбилдинг — от 7 000 ₽/чел.;
  • пробковый сбор, если площадка не указала, — 500–1 000 ₽/чел.;
  • правило «3 концепции / 3 площадки / 3 сметы».
- Цены, нормативы, словари, шаблоны — в настройках, не в коде.
- Даты и дни недели считай кодом, а не ИИ.
- Площадки — каждый раз поиск в интернете с проверкой, что работают.
- Логины и токены — только в защищённом хранилище.
- Кнопки — только где нужно моё решение; остальное агент делает сам.

ЕСЛИ ЧТО-ТО НЕЯСНО
Если в ТЗ что-то неясно или противоречит — не угадывай, спроси одним сообщением со списком вопросов.
