# Восстановление после ошибки "401 OAuth access token has expired"

Бот **kivi_agent_bot** (Telegram) работает на сервере Beget (IP: `109.69.19.107`,
имя сервера "Киви агент") под пользователем `agent`, используя Claude Code CLI.
Примерно раз в месяц OAuth-токен истекает, и бот начинает слать в Telegram:

```
Failed to authenticate. API Error: 401 OAuth access token has expired. Re-authenticate to continue.
```

## Рабочее решение (проверено 01.10.2026)

Консоль Beget (веб-VNC через cp.beget.com) **не поддерживает вставку из буфера
обмена** — вводить длинные ссылки/коды там нельзя. Поэтому используем
SSH через обычный терминал на компьютере (PowerShell / Командная строка),
где Ctrl+V работает нормально.

### Шаги

1. **Если пароль root неизвестен** — зайти в веб-консоль сервера через
   панель Beget (cp.beget.com → Облако → Виртуальные серверы → Киви агент →
   иконка консоли), войти как `root` с любым известным паролем, и задать
   новый через команду:
   ```
   passwd
   ```
   (ввести новый пароль дважды; он не отображается при вводе)

2. Открыть **PowerShell** или **Командную строку** на компьютере.

3. Подключиться по SSH:
   ```
   ssh root@109.69.19.107
   ```
   Ввести пароль root.

4. Переключиться на пользователя, от которого работает бот:
   ```
   su - agent
   ```

5. Запустить Claude Code:
   ```
   claude
   ```
   (согласиться "Yes, I trust this folder" при первом запуске в новой папке)

6. Если увидите 401 при любом запросе — выполнить:
   ```
   /login
   ```
   Выбрать первый пункт **"Claude account with subscription"**, нажать Enter.

7. Откроется/покажется ссылка для входа — скопировать её и открыть в браузере
   (в PowerShell ссылку можно выделить мышкой и Ctrl+C, либо клавишей `c`
   по подсказке "c to copy").

8. Войти в аккаунт (411040@gmail.com), подтвердить доступ — появится
   короткий код подтверждения.

9. Вернуться в окно PowerShell/терминала, кликнуть в поле
   "Paste code here if prompted", вставить код (**Ctrl+V** — в PowerShell
   работает нормально, в отличие от консоли Beget).

10. Должно появиться:
    ```
    Logged in as 411040@gmail.com
    Login successful. Press Enter to continue…
    ```
    Нажать Enter.

11. Проверить: написать что-нибудь в этом же окне Claude (например "привет")
    — должен ответить без ошибки. Затем проверить бота в Telegram.

## На будущее

Эта проблема повторяется из-за того, что используется обычный логин
(OAuth-сессия), у которой есть срок действия. Чтобы полностью убрать
проблему — можно настроить долгоживущий **API-ключ** вместо входа через
аккаунт (потребует правки в коде бота, чтобы он использовал
`ANTHROPIC_API_KEY` вместо OAuth-сессии).
